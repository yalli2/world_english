# World English — 세계사를 품은 영어 이야기

국제학교 영어 수업용 인터랙티브 학습 사이트 (교재: 『세계사를 품은 영어 이야기』, 필립 구든).

- 메인 페이지: 서문 + 16개 단원 (7개 파트)
- 단원별: 개요·연표, 읽기/듣기, 핵심 단어, 예문, 교재 자료 사진, 연습문제 10문항(채점·해설·오답 다시 풀기)
- 영어 발음: 브라우저 음성합성(Web Speech API), 미국/영국 발음·속도 선택
- 점수는 브라우저 localStorage에 저장됩니다.

정적 사이트이므로 GitHub Pages에서 그대로 동작합니다. 단원 데이터는 `data/chNN.js`에서 수정할 수 있습니다.
